## 11.2 How feedback is processed

1. The comment is entered in the log and in YouTrack (DIP-12) on the day it is received.
2. A decision is agreed with the supervisor: accept, adjust or decline with a reason.
3. The change is made on a branch, referenced in a pull request, and the commit or pull request link is added to the log.
4. The affected section of this report is updated in the next tagged version.
